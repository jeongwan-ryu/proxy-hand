# microbit/ — micro:bit 손 제어

- **MicroPython**이다. 일반 Python 패키지(pyserial, numpy, yaml 등)와 `shared/`를 쓸 수 없다. 표준 라이브러리도 일부만 있다. 메모리가 작으니 코드를 짧게 유지한다.
- 기술조사 때 만든 프로그램을 가져와 `M` 명령만 추가한다. 이미 되는 `P`, `S` 명령은 바꾸지 않는다.
- micro:bit ↔ 확장보드는 UART(P12/P8)로 연결되어 있다.

## 시리얼 명령 (`docs/05` 7장이 기준)

| 명령 | 뜻 | 응답 |
| --- | --- | --- |
| `P` | 연결 확인 | `OK` |
| `M a1 a2 a3 a4 a5 a6 ms` | 서보 6개를 한 번에 이동. 각도 0~180 정수, `ms` 0~1000 | `OK` / `ERR <이유>` |
| `S <서보> <각도> <ms>` | 서보 하나 이동 (보정 도구용) | `OK ...` / `ERR ...` |

- 115200bps, 명령 한 줄 = 글자들 + `\n`, 응답도 한 줄.
- 범위를 벗어난 각도는 움직이지 않고 `ERR range`를 보낸다 (`M`만. 기술조사의 `S`는 범위 밖을 잘라서 움직이며 그대로 둠).
- 켜질 때 서보를 움직이지 않는다 (시스템 설계 9.5). 시작하면 `READY` 한 줄을 보낸다.
- 확장보드가 주기적으로 보내는 `A...$` 때문에 명령이 깨지지 않게 수신 버퍼를 비우는 방식은 기술조사 코드를 그대로 쓴다.
- 노트북에서는 실행해 볼 수 없다. 바꾼 뒤에는 micro:bit에 올려 `P`, `M` 응답을 직접 확인한다.
