# ProxyHand 사용자 요구사항_이보연

* 작성일: 2026-11-16
* 수정일: 2026-11-18 (WonderCam 칸 표식 확인을 빼고 맵 위 웹캠 바닥 표식과 정지선으로 바꿈, AiHand 보정 방법 정리), 2026-11-17 (UR-12 작업차 2세트 동시 운용을 선택에서 필수로 변경, 시연 순서를 콕 → 버튼으로 변경, 시연 흐름을 작업차별 역할로 분리, 맵·카메라 역할·UR-03·UR-05·UR-12 확인 방법을 바뀐 맵에 맞춤, 시연 준비·측정기 투입구·반복 횟수·정지 후 규칙 추가)
* 기반 문서: ProxyHand 기획서\_이보연, ProxyHand 시연 구매 목록\_이보연
* 목적: ProxyHand 시연에서 사용자가 할 수 있어야 하는 것을 정리합니다. 개발과 시험은 이 목록을 기준으로 합니다.
* 범위: **이번 시연용 시제품**에 한정합니다. 실제 핫셀에 들어갈 제품의 요구사항은 다루지 않습니다.

## 1. 사용자

| 사용자 | 하는 일 |
| --- | --- |
| 조종자 (작업자 역할) | 모형 핫셀 창 앞에서 손을 움직여 조종하고, 시범을 보이고, 혼자 하기를 지켜봄 |
| 관람자 (멘토님, 심사위원) | 시연을 보고 작업이 성공했는지 바로 알아봄 |

## 2. 시연 환경

* **맵 (모형 핫셀):** 투명 상자 안을 **분주 구역**과 **측정 구역** 2개로 나눕니다. 구역마다 검정 테이프로 만든 고리 모양 길이 하나씩 있고, 작업차는 자기 구역의 고리만 돕니다. 정거장은 보관함(3칸), 작업대, 콕, 측정기, 대기 2곳이며, 작업대는 두 구역 사이에 있어 바이알을 넘겨주는 자리입니다.
* **작업차:** Raspbot 로보카 위에 AiHand(손가락 5개, 6축)를 붙인 세트 **2개** (작업차 1, 작업차 2)
* **카메라**

| 카메라 | 역할 |
| --- | --- |
| 노트북 웹캠 | 조종자의 손 인식 |
| 맵 위 웹캠 | 보관함 칸과 작업대 바닥의 표식이 바이알에 가려졌는지로 바이알 위치와 작업대에 바이알이 있는지 찾기, 콕 LED가 켜졌는지(= 약을 담았는지) 찾기 |
| 로보카 카메라 | 창으로 잘 안 보이는 손 주변을 보조 화면으로 보여 줌 (각 작업차의 카메라를 씀. 따로 카메라 차는 두지 않음) |

※ AiHand에 붙은 카메라(WonderCam)는 쓰지 않습니다. 작업차는 바닥의 정지선 수를 세어 정거장을 찾습니다.

* **시연 준비:** 시작 전에 보관함 3칸에 빈 바이알 3개를 넣고, 측정기 아래 수거함을 비우고, 콕을 닫아 둡니다. 측정기는 위가 뚫린 **투입구**라서 넣은 바이알이 아래 수거함으로 떨어집니다. 그래서 시연 중에는 사람이 바이알을 옮기지 않습니다.

## 3. 시연 흐름

### 작업차별 역할

실제 방사성의약품 제조실처럼 **약을 바이알에 담는 일(분주)**과 **방사능 양을 재는 일(측정)**을 두 작업차가 나눠 맡습니다. 두 작업차는 각자 구역 안에서만 움직이고, 두 구역 사이의 **작업대**에서 바이알을 넘겨줍니다.

| 작업차 | 구역 | 맡는 일 | 다니는 정거장 (순서대로) |
| --- | --- | --- | --- |
| 작업차 1 | 분주 구역 | 빈 바이알을 작업대에 놓고, 콕을 열고 닫아 약을 담음 | 대기 1 → 보관함 → 작업대 → 콕 → 대기 1 |
| 작업차 2 | 측정 구역 | 약을 담은 바이알을 작업대에서 집어 측정기 투입구에 넣고, 시작 버튼을 누름 | 대기 2 → 작업대 → 측정기 → 대기 2 |

### 순서

| 순서 | 조종자가 하는 일 | 작업차 1 (분주) | 작업차 2 (측정) |
| --- | --- | --- | --- |
| ① 집기 | 작업차 1을 손으로 조종 | 보관함의 바이알을 집어 작업대에 놓음 | 대기 |
| ② 돌리기 | 작업차 1을 손으로 조종 | 3방향 콕 손잡이를 집고 90° 돌려 열고 닫음 (열림 위치에서 LED가 켜짐) | 대기 |
| ③ 집기 + 누르기 | 작업차 2를 손으로 조종 | 대기 | 작업대의 바이알을 집어 측정기 투입구에 넣고, 시작 버튼을 누름 |
| ④ 가르치기 | ①~③을 가르치기 모드로 진행 | ①·②가 작업차 1의 작업으로 저장됨 | ③이 작업차 2의 작업으로 저장됨 |
| ⑤ 혼자 하기 | 두 작업차가 대기 정거장에 있을 때 시작만 누름. 진행자는 시작 전에 바이알을 놓는 칸을 바꿔 봄 | 바이알이 보관함 어느 칸에 있든 찾아가서 ①·②를 **보관함이 빌 때까지(바이알 3개)** 반복 | 약을 담은 바이알이 작업대에 나오면 가져가서 ③을 반복 |
| ⑥ 2세트 동시 운용 | 한 작업차를 정지시키고 손으로 직접 조종 | (예) 직접 조종을 받음. 하던 일을 손으로 마무리한 뒤 대기 정거장으로 보내야 다시 혼자 하기를 시작할 수 있음 | 혼자 하기를 계속함 |

※ 시연 순서(바이알 옮기기 → 콕 돌리기 → 버튼 누르기)는 실제 방사성의약품 준비 순서와 비슷하게 맞춘 것입니다. 실제로는 빈 바이알을 놓고, 콕을 열어 약을 바이알에 담은 뒤, 측정 장비로 방사능 양을 잽니다. 시연에서는 액체를 쓰지 않고, 콕이 열림 위치까지 돌면 LED가 켜지는 것으로 약이 흐르는 것을 대신 보여 줍니다.

## 4. 사용자 요구사항

### 필수

| ID | 요구사항 | 확인 방법 |
| --- | --- | --- |
| UR-01 | 조종자는 장갑 없이 웹캠 앞에서 손을 움직여 AiHand의 손가락과 손목을 조종할 수 있다 | 손을 쥐고, 펴고, 돌리면 AiHand가 같은 모양으로 움직인다 |
| UR-02 | 조종자는 정거장을 골라 작업차를 보낼 수 있고, 작업차는 그 정거장까지 스스로 가서 멈춘다 | 고른 정거장에 작업차가 멈춘다 |
| UR-03 | 조종자는 원격 조작으로 바이알을 집어 다른 정거장으로 옮길 수 있다 | 바이알이 넘어지지 않고 작업대(작업차 1)와 측정기(작업차 2)에 놓인다 |
| UR-04 | 조종자는 원격 조작으로 콕을 돌려 열고 닫을 수 있다 | 콕을 열림 위치로 돌리면 LED가 켜지고, 닫힘 위치로 돌리면 꺼진다 |
| UR-05 | 조종자는 원격 조작으로 측정기의 시작 버튼을 누를 수 있다 | 버튼의 LED가 켜진다 |
| UR-06 | 조종자는 원격 조작으로 한 작업을 시범 보이고, 그 작업을 저장할 수 있다 | 저장한 작업이 목록에 나타난다 |
| UR-07 | 조종자는 작업차가 대기 정거장에 있을 때 저장한 작업을 시작 버튼 하나로 실행할 수 있다 | 사람이 조종하지 않아도 작업이 끝난다 |
| UR-08 | 혼자 하기 중 바이알 위치가 바뀌어도 ProxyHand가 찾아가서 작업한다 | 바이알을 보관함의 다른 자리에 두고 실행해도 옮겨진다 |
| UR-09 | 조종자는 한 화면에서 보조 카메라 영상과 현재 모드(조종, 가르치기, 혼자 하기)를 볼 수 있다 | 화면만 보고 지금 모드를 말할 수 있다 |
| UR-10 | 조종자는 언제든 작업을 멈추고 직접 조종으로 넘겨받을 수 있다 | 정지를 누르면 바로 멈추고, 이어서 손으로 조종된다 |
| UR-11 | AiHand는 작업차가 정거장에 멈춰 있을 때만 조종자의 손을 따라 움직인다. 손 인식이 끊기면 AiHand는 마지막 자세를 그대로 유지하고, 손이 다시 인식되면 이어서 따라 한다 | 바이알을 쥔 상태에서 손을 카메라 밖으로 빼도 바이알을 떨어뜨리지 않는다 |
| UR-12 | 작업차 2세트를 동시에 운용한다. 조종자가 한 세트를 직접 조종하는 동안 다른 세트는 가르친 작업을 혼자 반복한다 | 작업차 2는 약을 다 담은 바이알만 가져가고, 두 작업차가 작업대에서 동시에 손을 뻗지 않으며, 화면에서 두 세트의 상태를 따로 볼 수 있다 |

※ 로보카 2대가 모두 작업차가 됩니다. 손 주변 보조 화면은 각 로보카의 카메라와 맵 위 웹캠이 맡습니다.

## 5. 측정 항목

목표 수치는 미리 정하지 않습니다. 시험에서 먼저 재 보고 적당한 목표를 정합니다.

| 항목 | 재는 방법 | 목표 |
| --- | --- | --- |
| 작업 성공률 | 집기, 누르기, 돌리기를 각각 여러 번 해서 성공한 비율 | 시험 후 결정 |
| 혼자 하기 성공률 | 바이알 위치를 바꿔 가며 혼자 하기를 여러 번 해서 성공한 비율 | 시험 후 결정 |
| 반응 지연 | 조종자가 손을 움직인 뒤 AiHand가 따라 움직이기까지 걸린 시간 | 시험 후 결정 |
| 작업 시간 | 같은 작업을 원격 조작으로 할 때와 혼자 하기로 할 때의 시간 | 시험 후 결정 |
| 연속 작동 시간 | 배터리 한 번 충전으로 시연을 반복할 수 있는 시간 | 시험 후 결정 |

## 6. 범위 밖

무거운 물건 다루기, 촉감 전달(햅틱), 방사선을 견디는 사양, 실제 핫셀 장착, 처음 보는 물건이나 배치에 대응하는 AI 학습은 이번 시연에서 다루지 않습니다.

## 7. 확인이 필요한 것

* **AiHand 무게와 Raspbot이 버티는지:** Yahboom 자료에 실을 수 있는 무게가 없어 직접 올려 봐야 합니다.
* **AiHand가 쥘 수 있는 바이알 굵기**
* **AiHand 힘으로 버튼이 눌리고 콕이 돌아가는지**
* **AiHand 2대가 같은 손 모양을 만드는지:** AiHand마다 손가락 각도가 조금씩 다를 수 있습니다. 한 대에서 잰 각도를 두 대에 같이 쓰고, 맞지 않는 손가락만 고칩니다.
* **맵 위 웹캠이 바닥 표식을 읽는지:** 웹캠 높이와 표식 크기에 따라 표식이 작게 찍혀 안 읽힐 수 있습니다.
* **작업차가 매번 같은 자리에 멈추는지:** 물건을 작업차가 멈추는 자리에 맞춰 놓으므로, 멈추는 자리가 매번 같아야 합니다.

### 장착이 안 될 때의 대체 계획

AiHand를 Raspbot 위에 붙여서 움직이기 어려우면(무게 때문에 주행이 불안정함, 작업 중에 차체가 밀림, 전원이나 연결이 불안정함), **손이 하는 작업과 로보카가 이동하는 장면을 따로 찍어 영상으로 합쳐서** 보여 줍니다.
